# Genuka Giyon Portfolio

A cinematic Streamlit portfolio for Genuka Giyon, focused on robotics, AI systems, embedded engineering, and real-world technical projects.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Upload these assets

Add your real files using these names so the portfolio picks them up automatically:

```txt
assets/images/profile/genuka-profile.jpg

assets/images/projects/icia-greenhouse/icia-medal-certificate-vietnam.png
assets/images/certificates/icia/icia-2025-bronze-certificate.pdf
```

## Streamlit Cloud

When deploying to Streamlit Cloud, set the app entry file to:

```txt
app.py
```

Keep `requirements.txt` in the root of the repository.
